# Personal Assistant — Production Starter

The complete modern project plus authentication, permissions, rate limiting, security headers, logging, monitoring endpoints, tests, Docker/cloud configuration, CI/CD and architecture documentation.

## Run on Windows

Double-click `run.bat`, or run `py ".\server.py"`. Open http://127.0.0.1:8000 and create the first administrator account.

## Test

`py -m unittest discover -s tests -v`

## Documentation

- `docs/SYSTEM_ARCHITECTURE.md`
- `docs/ENGINEERING_GUIDE.md`

This is an educational production-oriented starter, not a finished enterprise deployment.
